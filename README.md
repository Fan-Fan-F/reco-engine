# reco-engine · 商品推荐引擎

零依赖（原生 HTML/CSS/JS）的 **Item-CF 协同过滤推荐引擎**演示。从用户行为数据出发，完整实现"用户-商品矩阵 → 商品相似度 → 个性化推荐"全链路，并提供推荐解释。

## 功能

- **个性化推荐（猜你喜欢）**：选择用户，基于其行为历史实时计算 Top-6 推荐商品
- **可解释推荐**：每个推荐商品附带"因为你购买了 XX"的归因说明
- **看了又看（相似商品）**：选择任意商品，展示余弦相似度最高的关联商品
- **全站热门兜底**：解决新用户/新商品冷启动问题
- **行为权重体系**：浏览 ×1 / 加购 ×2 / 收藏 ×3 / 购买 ×5

## 算法

### 1. 用户-商品评分矩阵

同一用户对同一商品有多种行为时取最高权重：

```
matrix[user][item] = max(ACTION_WEIGHT[action])
```

### 2. 商品相似度（余弦相似度）

```
sim(a, b) = Σ_u(score[u][a] · score[u][b]) / (√Σ score[u][a]² · √Σ score[u][b]²)
```

每个商品只保留 Top-10 最近邻，控制计算量。

### 3. 推荐打分

```
score(user, item) = Σ (weight[user][seen] × sim(seen, item))
```

排除用户已行为的商品，按得分降序取 Top-N。

## 演示数据

`data.js` 内置 24 件商品、12 个用户，按 7 种兴趣模板（摄影/咖啡/健身/露营/桌面美学等）用可复现伪随机数生成行为事件，并有 30% 概率跨界浏览制造"共现桥接"——观察咖啡用户如何被推荐到瑜伽垫。

## 本地运行

直接用浏览器打开 `index.html` 即可。

## 生产化思路

- 共现矩阵离线预计算（Spark/Flink），线上只做向量乘加
- 加入时间衰减：`weight × exp(-Δt / τ)`，近期行为权重更高
- 多路召回（Item-CF + 热门 + 向量召回）后接排序模型
